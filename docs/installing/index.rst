=================
Installing LOCKSS
=================

.. tip::

   If you are upgrading an existing LOCKSS 2.0 installation to LOCKSS |LATEST_PATCH|, please see the upgrade instructions in the previous chapter (:doc:`/upgrading/index`) instead.

This chapter describes how to install LOCKSS |LATEST_PATCH|, the latest version of |LATEST_MINOR|, from scratch.

Before you begin the installation process, we recommend you first bring your operating system up to date by applying security updates and upgrading installed packages (ask your system administrator or see :doc:`/sysadmin/os-updates` in the appendix).
