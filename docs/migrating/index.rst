========================================
Migrating from LOCKSS 1.x to  LOCKSS 2.x
========================================

.. note::

   This chapter describes how to migrate from a LOCKSS 1.x system to LOCKSS 2.x system.
   This process will copy the preserved content, metadata if any, polling history, subscriptions, etc from your LOCKSS 1.x system to LOCKSS 2.x system
   The basic process is to install LOCKSS 2.x and configure it for migration and then configure LOCKSS 1.x for migration and start the migration.
   You can install LOCKSS 2.x on the same machine and do an in-place migration or on a different machine.
