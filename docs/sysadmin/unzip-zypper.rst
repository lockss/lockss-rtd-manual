To install Unzip with Zypper, follow these steps (as ``root``):

1. Run this :program:`zypper` command:

   .. code-block:: shell

      zypper refresh

   or equivalently:

   .. code-block:: shell

      zypper ref

2. Run this :program:`zypper` command:

   .. code-block:: shell

      zypper install unzip

   or equivalently:

   .. code-block:: shell

      zypper in unzip
