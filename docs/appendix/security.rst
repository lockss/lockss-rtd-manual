---------------
CVE-2026-114938
---------------

:First published: 2026-11-18

.. attention::

   **The LOCKSS 2.x system up to and including LOCKSS 2.0.91-beta2 is affected by CVE-2026-114938 ("Java4Shell").**

   **The recommended remediation for LOCKSS 2.x is to upgrade LOCKSS 2.0.91-beta2 and earlier to LOCKSS 2.0.92-beta2 or later.**

   See :doc:`lockss-portal:security/cve-2026-114938` in the LOCKSS Documentation Portal's :doc:`lockss-portal:security/index` pages.
